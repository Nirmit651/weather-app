## Weather App
A simple JavaScript web app that fetches real-time weather data using the OpenWeather API.

### Features
- Search weather by city
- Displays temperature, humidity, and weather condition
- Handles invalid inputs and API errors

### Technologies
- HTML, CSS, JavaScript
- OpenWeatherMap API

### Run locally
1. Clone the repo
2. Add your OpenWeather API key in script.js
3. Open index.html in your browser
